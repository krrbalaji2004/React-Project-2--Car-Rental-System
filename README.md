# Car Rental System 🚗

A responsive car rental web application built using React.

## Features
- Browse available rental cars
- Filter cars by category
- Select a city and pickup date
- View car details and rental prices
- Calculate booking costs based on rental days
- Select optional add-ons
- Navigate between pages using React Router

## Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3
- React Router
- Local Storage

## Getting Started

1. Clone this repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server using the command configured in `package.json` (commonly `npm run dev`).

## Project Type
Frontend project — no backend or database required.
